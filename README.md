# Converter para PDF

Ferramenta para **Windows 10/11 (64 bits)** que converte documentos web (`.html` / `.htm`)
em PDF **pelo botão direito do Explorer**: um ou centenas de arquivos de uma vez, sem abrir
janela, com o PDF salvo ao lado do original, sempre em folha A4 e sem cortar tabelas largas.

## Baixar e instalar

**[⬇ ConverterPDF-Setup.exe](https://github.com/helveciopereira/converter-pdf/releases/latest/download/ConverterPDF-Setup.exe)**

- Instala para o seu usuário, **sem pedir administrador**.
- Adiciona **Converter para PDF** ao botão direito em arquivos `.html` e `.htm`. No
  Windows 11, o item fica em "Mostrar mais opções" (ou `Shift + botão direito`).
- Usa o **Microsoft Edge**, que já vem no Windows (ou o Google Chrome).
- Na primeira vez, o Windows pode avisar que o aplicativo não é reconhecido: clique em
  **Mais informações → Executar assim mesmo**.

## Como usar

1. Selecione um ou mais arquivos `.html`/`.htm` no Explorer.
2. Botão direito → **Mostrar mais opções** → **Converter para PDF**.
3. Uma notificação avisa quando terminar; clique nela para abrir o PDF ou a pasta.

Se o PDF já existir, é criado `nome (2).pdf`: nenhum PDF existente é apagado.

## Atualização automática

O programa se atualiza sozinho e em silêncio: depois de uma conversão, verifica se há
versão nova, baixa e instala sem mostrar nada.

## Desinstalar

Configurações → Aplicativos → Converter para PDF → Desinstalar. O item do botão direito
também é removido.
